## Матриця нефункціональних вимог (NFRs Matrix)

Повний перелік (NFR-01 – NFR-19) наведено в [1_analysis.md](1_analysis.md), підрозділ 1.5.3.

| Ід. | Категорія | Цільове значення |
|---|---|---|
| NFR-01 | Продуктивність | API читання: p95 ≤ 200 мс при 200 RPS |
| NFR-02 | Продуктивність | API запису: p95 ≤ 300 мс при 50 RPS |
| NFR-04 | Продуктивність | Імпорт операції → оновлений розрахунок: p95 ≤ 5 с |
| NFR-06 | Масштабованість | Kubernetes HPA 2–6 реплік; Kafka ≥ 6 партицій, ключ `tenant_id` |
| NFR-07 | Надійність | Доступність API ≥ 99,5 % (SLO) |
| NFR-08 | Надійність | At-least-once + ідемпотентні консюмери: 0 дублікатів |
| NFR-10 | Надійність | PostgreSQL PITR: RPO ≤ 15 хв, RTO ≤ 1 год |
| NFR-11 | Коректність | 100 % відтворюваних розрахунків; CI-гейт на golden tests |
| NFR-12 | Безпека | OAuth 2.0 / OIDC (Keycloak), JWT RS256, TTL 15 хв |
| NFR-13 | Безпека | Row-Level Security: 0 доступів до даних іншого тенанта |
| NFR-15 | Безпека | OWASP ASVS 4.0 L2; SonarQube 0 Blocker/Critical; Trivy 0 Critical CVE |
| NFR-18 | Спостережуваність | OpenTelemetry: 100 % помилкових і ≥ 10 % успішних запитів |
